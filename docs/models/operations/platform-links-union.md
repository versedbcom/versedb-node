# PlatformLinksUnion

Links by name, or null; an empty map prints as `[]`.


## Supported Types

### `operations.PlatformLinks`

```typescript
const value: operations.PlatformLinks = {
  spotify: "https://open.spotify.com/show/abc123",
};
```

### `string`

```typescript
const value: string = "<value>";
```

### `number`

```typescript
const value: number = 1284.03;
```

### `boolean`

```typescript
const value: boolean = true;
```

### `any[]`

```typescript
const value: any[] = [
  "<value 1>",
  "<value 2>",
  "<value 3>",
];
```

### `{ [k: string]: any }`

```typescript
const value: { [k: string]: any } = {
  "spotify": "https://open.spotify.com/show/abc123",
};
```
