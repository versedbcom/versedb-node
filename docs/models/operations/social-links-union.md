# SocialLinksUnion

Links by name, or null; an empty map prints as `[]`.


## Supported Types

### `operations.SocialLinks`

```typescript
const value: operations.SocialLinks = {
  website: "https://warrocketajax.com",
};
```

### `any[]`

```typescript
const value: any[] = [
  "<value 1>",
  "<value 2>",
  "<value 3>",
];
```
